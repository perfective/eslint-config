= `perfectionist`
:perfectionist-rules: https://perfectionist.dev/rules

The `link:https://perfectionist.dev[eslint-plugin-perfectionist]` provides
rules to sort objects, imports, types, JSX props, and other code elements.

Only the `perfectionist/sort-jsx-props` rule is enabled.
It replaces the deprecated `@stylistic/jsx-sort-props` rule.

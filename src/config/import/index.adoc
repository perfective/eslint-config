= `import-x`
:eslint-import-x-rules: https://github.com/un-ts/eslint-plugin-import-x/blob/master/docs/rules

The `link:https://github.com/un-ts/eslint-plugin-import-x[eslint-plugin-import-x]` provides rules
for the ES2015+ (ES6+) import/export syntax
to prevent issues with misspelling of file paths and import names.
